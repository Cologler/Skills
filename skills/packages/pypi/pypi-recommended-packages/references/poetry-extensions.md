# Poetry Extensions

**poetry-dynamic-versioning**: [github](https://github.com/mtkennerly/poetry-dynamic-versioning) #versioning #packaging\
Choose to derive Poetry project versions from version-control tags during builds, instead of manually updating version fields for each release.

**poetry-audit-plugin**: [github](https://github.com/opeco17/poetry-audit-plugin) #security #audit\
Choose to check Poetry project dependencies for known vulnerabilities with `poetry audit`, using Safety's vulnerability database.

**poetry-plugin-sort**: [github](https://github.com/andrei-shabanski/poetry-plugin-sort) #dependencies #sorting\
Choose to sort dependencies in `pyproject.toml` automatically after `poetry init` or `poetry add`, or on demand with `poetry sort`, instead of maintaining their order by hand.
